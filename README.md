# STM32F103C8T6 四轮智能车

以 STM32F103C8T6 为主控、两块 TB6612FNG 驱动四个直流电机的个人学习项目。当前公开电机控制与 OLED 基础工程，后续在同一项目中逐步加入 HC-05 蓝牙遥控、SG90 舵机和 HC-SR04 测距避障。

**当前为持续开发的基础版本：蓝牙程序尚未编写，自动避障尚未实现。默认主循环不执行运动动作。**

## 已有代码与待开发功能

| 模块 | 当前源码状态 | 验证边界 |
| --- | --- | --- |
| 四路 PWM | TIM2 CH1–CH4，PA0–PA3，独立设置比较值 | 静态代码可核对；不代表四轮速度闭环 |
| 电机方向 | 四组 GPIO 方向控制函数 | 轮位和实际正反转需逐轮实测 |
| 整车动作 | 停止、三档前进、后退、左右转向函数 | 已定义；默认 main 未调用，整车效果待记录 |
| OLED | PB8/PB9 软件 I2C，初始化和文本显示 | 显示的是设定占空比，不是测速数据 |
| HC-05 | `HC-05.c/.h` 占位 | 未实现初始化、接收与命令解析 |
| SG90 | `Servo.c` 空函数 | 未实现舵机 PWM 与角度控制 |
| HC-SR04 | `UltraSonic.c/.h` 占位 | 未实现回波测时、超时与距离计算 |
| 保护和自动控制 | 无有效命令超时、模式仲裁与避障状态机 | 后续开发，不能视为已具备 |

截至 2026-10-26，以上状态依据当前源码和作者最新确认。没有发布实物验收视频或性能指标；编译结果也不代替硬件测试。

## 快速开始

1. 克隆仓库，用 Keil µVision 打开根目录 `Project.uvprojx`。
2. 按 [构建说明](docs/BUILD.md) 安装相应编译器和器件包，核对主控为 STM32F103C8T6。
3. 对照 [硬件与引脚](docs/HARDWARE.md) 检查接线、共地、供电和 STBY。
4. 编译并下载前先读 [测试步骤与已知问题](docs/TESTING.md)。当前默认程序只初始化 OLED、PWM 和方向 GPIO，不会主动调用前进或蓝牙控制。

## 工程结构

```text
User/           主程序、配置与中断模板
Hardware/       PWM、电机、整车动作、OLED；蓝牙/舵机/超声波占位
Start/          ST 启动文件、系统时钟与 ARM CMSIS
Library/        STM32F10x 标准外设库 V3.5.0
docs/           接线、构建、验证和扩展计划
Project.uvprojx Keil 工程入口
```

保持现有结构，便于和学习代码对照；尚未引入 RTOS、HAL 迁移或通用插件框架。模块完成后再根据实际调用关系调整接口。

## 后续方向

先验证单轮与基础动作、补停止行为，再完成蓝牙指令和命令超时保护；随后独立验证舵机和超声波，最后接入停车扫描与低速避障。编码器测速、PID 和循迹作为更后面的可选模块。

具体资源规划、阶段验收和接口边界见 [开发路线](docs/ROADMAP.md)。新增功能先在分支开发，完成代码、接线与实测记录后再更新本页功能状态。
