# STM32F103C8T6 四轮智能车

以 STM32F103C8T6 为主控、两块 TB6612FNG 驱动四个直流电机的个人学习项目。当前源码包含 HC-05 蓝牙遥控、四轮电机控制与 OLED 显示。

上电后等待蓝牙指令。`S` 停车，蓝牙断开或停止发送指令时，当前程序不会自动停车。

## 已有代码与待开发功能

| 模块 | 当前源码状态 | 验证边界 |
| --- | --- | --- |
| 四路 PWM | TIM2 CH1–CH4，PA0–PA3，独立设置比较值 | 静态代码可核对；不代表四轮速度闭环 |
| 电机方向 | 四组 GPIO 方向控制函数 | 轮位和实际正反转需逐轮实测 |
| 整车动作 | 停止、三档前进、后退、左右转向 | 由蓝牙指令触发，整车动作待实测 |
| OLED | PB8/PB9 软件 I2C，显示动作与左右 PWM 设定值 | 车轮实际速度待实测 |
| HC-05 | USART1，9600 8N1，轮询接收单字节指令 | 接线和蓝牙联调待实测 |
| SG90 | `Servo.c` 空函数 | 未实现舵机 PWM 与角度控制 |
| HC-SR04 | `UltraSonic.c/.h` 占位 | 未实现回波测时、超时与距离计算 |
| 保护和自动控制 | 无有效命令超时、模式仲裁与避障状态机 | 后续开发，不能视为已具备 |

## 蓝牙指令

通过 HC-05 发送单个 ASCII 字符。`1`、`2`、`3` 对应前进三档，`B` 后退，`L` 左转，`R` 右转，`S` 停止。其他字符会被忽略。

## 快速开始

1. 克隆仓库，用 Keil µVision 打开根目录 `Project.uvprojx`。
2. 按 [构建说明](docs/BUILD.md) 安装相应编译器和器件包，核对主控为 STM32F103C8T6。
3. 对照 [硬件与引脚](docs/HARDWARE.md) 检查接线、共地、供电和 STBY。
4. 编译并下载前先读 [测试步骤与已知问题](docs/TESTING.md)。首次验证时架空车轮，先核对上电静止和 `S` 停车。

## 工程结构

```text
User/           主程序、配置与中断模板
Hardware/       PWM、电机、整车动作、OLED、HC-05；舵机和超声波占位
Start/          ST 启动文件、系统时钟与 ARM CMSIS
Library/        STM32F10x 标准外设库 V3.5.0
docs/           接线、构建、验证和扩展计划
Project.uvprojx Keil 工程入口
```

保持现有结构，便于和学习代码对照；尚未引入 RTOS、HAL 迁移或通用插件框架。模块完成后再根据实际调用关系调整接口。

## 后续方向

先验证单轮、蓝牙动作和停车，再加入命令超时保护。随后开发舵机和超声波驱动，再接入停车扫描与低速避障。编码器测速、PID 和循迹作为更后面的可选模块。

具体资源规划、阶段验收和接口边界见 [开发路线](docs/ROADMAP.md)。新增功能先在分支开发，完成代码、接线与实测记录后再更新本页功能状态。
