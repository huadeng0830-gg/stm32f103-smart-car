# 硬件与引脚

本表按当前源码整理，表示程序输出分配。实际轮位、驱动板 A/B 通道、线序和电机方向仍需实物核对。主控为 STM32F103C8T6。

## 当前分配

| 电机编号 | 源码注释轮位 | PWM | 方向脚 1 | 方向脚 2 | Forward 电平 |
| --- | --- | --- | --- | --- | --- |
| M1 | 右前 | PA0 / TIM2_CH1 | PA4 | PA5 | 0 / 1 |
| M2 | 右后 | PA1 / TIM2_CH2 | PA6 | PA7 | 0 / 1 |
| M3 | 左前 | PA2 / TIM2_CH3 | PB0 | PB1 | 1 / 0 |
| M4 | 左后 | PA3 / TIM2_CH4 | PB10 | PB11 | 1 / 0 |

Backward 为对应电平反向。OLED 使用 PB8 作 SCL、PB9 作 SDA，为 GPIO 开漏软件 I2C；源代码写入的 8 位地址是 `0x78`。

TIM2 预分频为 `36-1`，自动重载值为 `100-1`，比较值使用 0–100 表示占空比设定。按当前系统配置成功运行在 72 MHz、APB1 定时器时钟为 72 MHz 的前提计算，PWM 频率为 `72 MHz / 36 / 100 = 20 kHz`。这里是配置推算，尚非示波器实测值。

## 供电与驱动板

- 两块 TB6612FNG 合计提供四路直流电机驱动。每一路连接正确的方向输入、PWM 输入和电机输出；不根据线色直接推断车轮前后方向。
- 逻辑电源、电机电源及允许电流按实际驱动模块和电机规格核对，所有控制信号共地。
- 当前代码没有控制 STBY 的 GPIO，接线必须单独记录 STBY 怎样进入工作状态。未使能、缺少共地或电源能力不足均会影响测试。
- SWD 的 PA13/PA14 留给下载调试。默认程序不主动运动，但初始化占空比为 0 不能替代电气与实物停止验证。

## 后续候选资源

以下为规划，**尚未配置或验证**；最终分配要与所用 LQFP48 板卡引出脚核对。

| 模块 | 候选分配 | 选择原因与约束 |
| --- | --- | --- |
| HC-05 UART | USART1：PA9 TX、PA10 RX | 避开已用于电机的 PA2/PA3，不使用默认 USART2 |
| SG90 信号 | TIM1_CH1：PA8 | 使用独立于电机 TIM2 的定时器，另行配置控制脉冲周期 |
| HC-SR04 Trig | PB12 GPIO 输出 | 当前工程未占用 |
| HC-SR04 Echo | PB6 / TIM4_CH1 输入捕获 | 候选测时资源；不与 OLED PB8/PB9 共用外设功能 |

不要把舵机直接接到现有 PA6/PA7 或 PB0/PB1，也不要把超声波接到 PB10/PB11，这些脚已有电机方向用途。未来使用编码器时重新分配定时器，不预先承诺四路编码器接口。

HC-05 波特率和发送格式尚未确定；需根据实际模块配置设计。SG90 的独立供电、机械行程和脉宽范围应先单独校准。HC-SR04 的 Echo 电平按模块与 MCU 输入条件核对，先做好电平匹配，再接线测量。
